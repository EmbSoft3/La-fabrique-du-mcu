Mk est un système d'exploitation temps réel (RTOS) ciblant les microcontrôleurs STM32F7 (cœur ARM Cortex-M7). Cette page présente l'ensemble des API développées pour ce système d'exploitation.

1. Le noyau temps réel Mk

✔ Architecture du noyau Cet article présente l'architecture du noyau temps réel Mk. Il se concentre sur les mécanismes d'ordonnancement, les listes de tâches, les droits, les vecteurs d'interruption et les interactions du noyau avec la FPU et la MPU.

Mk est un système d'exploitation temps réel (RTOS) ciblant les microcontrôleurs STM32F7 (cœur ARM Cortex-M7). Cette page présente l'ensemble des API développées pour ce système d'exploitation.

1. Le noyau temps réel Mk

✔ Préambule Cet article présente l'architecture et les fonctionnalités du noyau temps réel Mk. Il se concentre sur les mécanismes d'ordonnancement, les listes de tâches, les droits, les vecteurs d'interruption et les interactions du noyau avec la FPU et la MPU.
✔ Téléchargement et compilation du noyau Cet article décrit la méthodologie à utiliser pour récupérer le code source du noyau, installer la chaine de compilation et exécuter son premier projet.
✔ Initialisation du noyau Cet article présente l'initialisation du noyau, la configuration de la tâche de repos et la configuration du tick système.
